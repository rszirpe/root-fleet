# Root Fleet

Open the app: **https://rszirpe.github.io/root-fleet/**

Root Fleet is a front-end-only simulator and Web Bluetooth controller for iRobot Root rt0/rt1 robots. It opens without an account or access code. The app includes custom maps, calibrated tiles, fleet routing, editable Python export, and a local Developer Studio.

Start with **Simulate Fleet**. For a physical run, use a Web Bluetooth browser such as Chrome or Edge on HTTPS, connect each placed robot, position them at the displayed starts and headings, then choose **GO - Run Fleet**. See [the fleet guide](FLEET-GUIDE.md) for setup and safety details.

The repository and hosted app are public. Anyone with or without the link can view and download the source. Browser simulation and mock-Bluetooth checks passed; physical robot operation has not been validated in this release. [Validation details](VALIDATION.md).
